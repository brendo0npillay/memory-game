# Memory Game

An interactive memory matching game built with vanilla JavaScript. Flip cards, find matching pairs, track your time and flip count, and challenge yourself with multiple grid sizes for increasing difficulty.

## **Features**

- Classic card-matching memory gameplay
- Multiple grid sizes (2×2, 3×2, 4×2, 4×3)
- Real-time game timer
- Flip counter to track performance
- Visual feedback for matches and mismatches
- Restart game at any time
- Win modal displaying completion time and total flips
- Shuffled cards on every new game
- Smooth click-locking to prevent rapid flipping exploits

## **Technologies Used**

- Vanilla JavaScript
- HTML5
- CSS
- Bootstrap (modals & layout utilities)
- Webpack (bundling)
- JSON (image/game data)

## Usage

1. Open the game in your browser

2. Click a card to flip it

3. Match two identical cards to score

4. Avoid mismatches to minimize flips

5. Track your time and flip count

6. Change grid size to increase difficulty

7. Restart anytime or after winning
